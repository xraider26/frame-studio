# MCP configuration examples

Use **Connections & MCP** in your running studio to obtain the command, arguments and data path for your own installation. The desktop app also has **Frame Studio → Copy MCP configuration**. Keep Frame Studio open while using the agent.

`mcp-clients.json` and `codex-config.toml` show the source-checkout formats only. Their `C:/path/to/frame-studio` paths are placeholders, not a required folder or a working configuration to paste unchanged. The installed Windows app uses its bundled `FrameStudioService.exe` instead of Python and a script.

Merge only the Frame Studio entry into existing client settings; do not overwrite other MCP servers. Tokens and API keys do not belong in these examples. Reconnect your client after changing its configuration. See the [MCP guide](../docs/MCP.md).
