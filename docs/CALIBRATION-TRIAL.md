# Calibration trial and source handover

Source workflow: ask generators once per project, ask again only when affected choices change; use one representative still; record the exact submitted prompt, references and arguments; inspect technical quality; wait for the creator to accept or reject style. Rejection retains the take and permits targeted repair. Acceptance applies to the recorded shared style contract, not missing identity/product fidelity. Agents cannot accept, skip or impersonate creator decisions.

Built-in image tools receive avoidance constraints inside the frozen compiled prompt because they have no native negative-prompt argument. Unknown model versions and capabilities remain unknown.
