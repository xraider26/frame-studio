# Orchestra 0.3.0-beta.1

Orchestra helps creators and connected AI agents agree on tools, calibrate a visual direction, and keep production evidence together. This Windows x64 beta includes all image-project and ComfyUI work since the earlier published Frame Studio beta.

## Highlights

- **Generator setup once per project.** Ask which image/video tools will be used, remember the answer, and reopen only affected choices after a change. Built-in image tools may have managed, unknown model versions. A saved tool name does not imply a verified API connection.
- **One-image creator calibration.** Prepare a representative still, record technical inspection, then wait for the creator to accept or reject its style. Rejection retains the take and enables targeted repair. Agents cannot approve or skip calibration; queue and provider execution enforce the same gate. Environment-style acceptance does not waive required identity or product references.
- **Exact execution evidence.** Inspect applicable course-rule bindings, compiled versus submitted prompts, actual reference versions and request arguments. Distinguish server-captured requests from agent-reported evidence. Missing/mismatched evidence retains real output for review. Built-in image avoidance constraints are compiled into the frozen prompt before claiming.
- **Smaller agent handoffs.** Schema-3 claims contain one top-level handoff; polling returns summaries. Fetch versioned context and catalog details when needed. Synthetic fixture: 301,679 → 11,920 minified UTF-8 bytes (96.05% smaller); bootstrap 8,760 bytes. These are byte measurements, not billed-token or credit estimates. Required instructions are never truncated.
- **Windows reliability.** Resolve a stable physical writable root, refuse competing state without merging databases, and verify service discovery against its instance, PID and data root. Errors distinguish startup from a later service exit. Restart shuts down owned children and preserves data.
- **Image and video workflow.** Image-only projects, seven image formats, seven editable video sequence patterns, five-stage navigation, direct uploads, structured image requirements, Qwen guidance and mapped ComfyUI execution.

## Download and upgrade

Download `Orchestra-Setup-0.3.0-beta.1.exe` and its `.sha256` checksum from this release. Close Orchestra before upgrading. Existing Frame Studio data stays under the legacy per-user data directory; no live project is silently opted into the new calibration policies. Back up the data folder before upgrading. The unsigned Windows installer may show SmartScreen warnings. No generation provider, subscription or API key is included.

## MCP compatibility

`claim_generation` defaults to compact schema 3: use `job.id` and the top-level `handoff`. Request `response_format="legacy"` for the earlier shape. `get_job`/`get_project` default to summaries; request execution/full detail when needed. Historical stored v2 jobs remain immutable. See [MCP migration details](../MCP.md).
