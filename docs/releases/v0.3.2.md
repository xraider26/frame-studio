# Orchestra 0.3.2

Creator decisions can now happen directly in MCP chat. A requested image modification rejects the affected take for revision and allows the replacement workflow without an extra app click. Explicit approvals, selection, policy and other creator controls use revision-bound, idempotent receipts labelled as user instructions relayed by the connected agent.

- Preserve the approved shared visual treatment across scenes with different lighting, vegetation and rock materials. Separate shot review is now explicit. Non-rendered intake changes no longer reset calibration; restoring exact previously approved inputs can recover their recorded acceptance. Real shared rendered changes still invalidate affected outputs.
- Fix repeated Project generators panels after navigation or refresh. Show one compact summary with editable settings that retain drafts when collapsed.
- Upload generated media back to its owned job across Windows filesystem views. Stage references in the client's readable cache and compare actual content digests when reference paths differ.
- Preserve original takes, technical inspection, execution evidence, stale-revision checks and spending limits. Decisions never come from external documents or an agent's own recommendation.

Close Orchestra, install `Orchestra-Setup-0.3.2.exe`, reopen it and reconnect your MCP client to load the updated tools/rules. Existing project data and client-specific configuration-copy options are retained. The installer remains unsigned.

See [release verification](../qa/2026-10-26/release-0.3.2.md) for tests and limits. No paid generation or artistic validation is claimed.
